# Supabase setup

1. Create/open a Supabase project.
2. Run `schema.sql` in the SQL Editor.
3. Create a frontend environment with:
   - SUPABASE_URL
   - SUPABASE_PUBLISHABLE_KEY
4. Never put a service-role/secret key in browser code.
5. Enable email/password authentication if using the login UI.

The database is designed for demo credits only. It does not implement deposits, withdrawals, real-money wagers, or payment processing.
